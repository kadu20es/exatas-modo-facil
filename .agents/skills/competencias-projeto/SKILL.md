# Competências Técnicas (Skills)

Para executar as especificações deste projeto com sucesso, o agente (Codex/IA) e/ou desenvolvedor deve possuir as seguintes proficiencies:

## 1. Engenharia de Frontend (Core)
* **React.js (Avançado):** 
  * Domínio profundo do ciclo de vida dos componentes.
  * Maestria em Hooks (`useState`, `useEffect`, `useMemo`, `useCallback`, `useRef`).
  * Capacidade de pensar em componentes de forma atômica e reutilizável.
* **TypeScript (Avançado):**
  * Criação de interfaces e types estritos para dados complexos (ex: tipos variados de exercícios matemáticos).
  * Tipagem de propriedades de componentes React (`React.FC<Props>`).
* **Roteamento:** 
  * Proficiência em `react-router-dom` v6+ (criação de layouts aninhados, outlets, params).

## 2. Estilização e UI
* **Tailwind CSS (Intermediário/Avançado):**
  * Tradução de regras CSS inline e customizadas para classes utilitárias do Tailwind.
  * Conhecimento de configuração do `tailwind.config.js` para estender cores legadas (ex: `--ink`, `--paper`).
* **CSS Moderno:**
  * Uso de CSS Grid e Flexbox para layouts complexos.
  * Compreensão de especificidade e variáveis CSS (Custom Properties).

## 3. Integrações Específicas
* **KaTeX / LaTeX:**
  * Conhecimento sobre a sintaxe do KaTeX e como injetá-lo de forma segura no DOM do React sem causar bugs no Virtual DOM.
* **HTML5 Canvas:**
  * Capacidade de migrar rotinas de desenho imperativo (`ctx.arc`, `ctx.rect`) atrelando-as a ciclos do `useEffect` observando mudanças de estado (ex: laboratório da pizza de frações).

## 4. Engenharia Reversa e Refatoração
* **Vanilla JavaScript:** 
  * Leitura e interpretação de código legado de forma fluente.
  * Capacidade de "desembaraçar" lógica de estado (acoplada ao DOM) e convertê-la em estado reativo.
* **Arquitetura de Dados:**
  * Habilidade de modelar esquemas de dados estáticos (JSON/TS Modules) a partir de variáveis soltas no código.
